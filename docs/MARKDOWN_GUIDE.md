# 글쓰기용 Markdown 참고서

Memorying의 글 본문은 `src/content/writing/<슬러그>/ko.md`, `en.md`에 씁니다. 이 문서는 글을 쓰면서 찾아보는 문법 참고서입니다. 글 생성·공개 방법은 [운영 가이드](MAINTENANCE.md)를 참고하세요.

## 파일의 기본 모양

```markdown
---
title: "기억에 관하여"
---

첫 번째 문단입니다.

두 번째 문단입니다.
```

맨 위 두 `---` 사이가 제목 정보(frontmatter)입니다. `title`만 두고 `description`은 추가하지 않습니다. 날짜·글 종류·원문 언어·공개 여부는 별도 `meta.yaml`에 둡니다. 한국어와 영어 파일을 모두 유지하세요. 제목은 화면에서 자동으로 표시하므로 본문에 `# 제목`을 반복하지 않아도 됩니다. 제목 값에는 본문용 `**`나 `*`를 쓰지 마세요.

## 자주 쓰는 문법

| 기능 | 입력 예시 | 표시 의미 |
| --- | --- | --- |
| 굵게 (bold) | `**중요한 말**` | **중요한 말** |
| 기울임 (italic) | `*기억의 조각*` | *기억의 조각* |
| 굵게 + 기울임 | `***아주 중요한 말***` | ***아주 중요한 말*** |
| 취소선 | `~~지운 말~~` | ~~지운 말~~ |
| 인라인 코드 | `` `ko.md` `` | `ko.md` |
| 링크 | `[사이트](https://sunwoochoi.com)` | [사이트](https://sunwoochoi.com) |
| 기호 그대로 | `\*별표\*` | \*별표\* |

강조 기호와 글자 사이에 공백을 넣지 않습니다. `** 중요한 말 **` 대신 `**중요한 말**`로 씁니다. 글꼴에 따라 한국어 기울임이나 영어 굵기의 인상이 다를 수 있으므로 사이트 미리보기에서 확인하세요. 밑줄·글자색·형광펜은 기본 Markdown 문법이 아닙니다.

## 문단과 줄바꿈

문단 사이는 빈 줄 하나로 나눕니다. 편집기에서 Enter를 한 번 누른 것만으로는 화면에서 줄이 나뉘지 않을 수 있습니다.

```markdown
첫 번째 문단.

두 번째 문단.
```

같은 문단 안에서 반드시 줄을 바꾸려면 줄 끝에 역슬래시(`\`)를 붙입니다. 줄 끝 공백 두 칸도 같은 역할을 하지만 눈에 보이는 역슬래시가 관리하기 쉽습니다.

```markdown
첫 번째 행.\
두 번째 행.
```

## 소제목

글 제목 아래의 큰 구분에는 `##`, 그 안의 작은 구분에는 `###`를 씁니다. `#` 뒤에는 공백이 필요합니다.

```markdown
## 첫 번째 기억

본문입니다.

### 그날의 장면

본문입니다.
```

## 인용문

```markdown
> 기억은 언제나 현재의 언어로 돌아온다.
>
> 인용 안의 두 번째 문단입니다.

인용이 끝난 뒤 내 문장입니다.
```

인용문 앞뒤를 빈 줄로 나눕니다. 출처는 필요한 위치에 직접 적습니다.

## 목록과 체크리스트

```markdown
- 첫 번째 항목
- 두 번째 항목
  - 두 번째 항목의 하위 항목

1. 먼저 할 일
2. 다음 할 일

- [ ] 아직 하지 않은 일
- [x] 끝낸 일
```

목록 앞뒤에도 빈 줄을 둡니다. 체크리스트는 글에 표시되는 상태이며, 독자가 클릭해서 저장하는 기능은 아닙니다.

## 구분선

본문 중간에서 앞뒤에 빈 줄을 두고 `---`를 쓰면 구분선이 됩니다. 바로 위 문장과 붙이면 제목 문법으로 해석될 수 있습니다.

```markdown
앞부분의 마지막 문장.

---

다음 부분의 첫 문장.
```

## 링크와 이미지

```markdown
[다른 글 읽기](/writing/alone/)

![사진에 대한 짧은 설명](/images/my-photo.jpg)
```

이미지 예시는 먼저 `public/images/my-photo.jpg`에 사진을 넣었을 때의 주소입니다. `public/`은 주소에서 제외합니다. `my-photo.jpg`는 예시 파일명이므로 실제 파일명으로 바꾸세요. 설명은 사진을 볼 수 없는 독자에게 내용을 전하는 대체 텍스트입니다.

글 상단의 대표 사진은 본문 이미지와 별개입니다. 기존 `cover.*` 규칙은 [운영 가이드](MAINTENANCE.md)의 사진 항목을 따르세요.

## 표

```markdown
| 항목 | 내용 |
| --- | --- |
| 장소 | 서울 |
| 날짜 | 2026-09-26 |
```

표·취소선·체크리스트는 이 프로젝트의 Markdown 처리기가 지원하는 확장 문법입니다. 표는 휴대폰에서도 읽기 쉽도록 열 수와 내용을 짧게 유지하세요.

## 미리보기와 문법 검토

편집기의 Markdown 미리보기와 실제 사이트는 글꼴·간격이 다를 수 있습니다. 사이트 표시를 확인하려면 프로젝트의 비공개 개발 미리보기를 사용하세요. 표시는 브라우저에서, 문법 판단은 별도로 확인합니다.

이 프로젝트에서 “`demian/ko.md` 문법 확인해 줘” 또는 “이 글의 한국어와 영어 맞춤법을 확인해 줘”라고 요청하면 [문법 검토 스킬](../skills/review-grammar/SKILL.md)을 사용하도록 [프로젝트 지침](../AGENTS.md)에 지정되어 있습니다. 검토는 **원문을 수정하지 않고**, 위치·원문·최소 수정 제안·이유·판단을 대화로 전달합니다. 실제 수정은 저자가 선택해 반영합니다.
